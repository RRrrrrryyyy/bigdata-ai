3个人解释

想象你雇了一位特别能干的实习生。普通 AI 聊天机器人像一部"问答机"：你问一句，它答一句，答完就停下等你。而 Agent 更像那位实习生——你只交代目标（"帮我订下周去上海的出差行程"），它会自己拆解任务：先查日历确定日期，再比价机票和酒店，看一眼天气预报决定要不要提醒你带伞，遇到价格异常还会换个平台重新查。

两者的本质区别不在"聪明程度"，而在控制权归属：聊天机器人每说一句话都把方向盘交回给你；Agent 则在拿到目标后，由它自己决定下一步做什么、调用什么工具、什么时候停。官方媒体的通俗定义是：Agent 是"能够感知环境并利用工具采取行动以实现特定目标的代理"。

如果只能记住一句话：Agent = 模型在循环中自己决定"下一步做什么"的自主任务执行系统——人给目标，模型定路径。

4核心机制

起源

Agent 是人工智能领域的经典概念，其现代形态由大语言模型（LLM）点燃：OpenAI 将其描述为"以大语言模型为大脑，整合感知、规划、记忆与工具调用能力的自主系统"。2024 年 12 月，Anthropic 发布工程指南《Building Effective Agents》，给出了业界广泛引用的区分标准，使这一概念在产业界快速普及。

原理：目标 → 观察 → 行动 的循环

  1. 接收目标：用户用自然语言下达任务，而非逐步指令；
  2. 规划（Planning）：LLM 把复杂目标拆解为可执行的子任务序列；
  3. 行动（Action）：通过调用工具（搜索、API、代码执行、文件读写）影响真实世界；
  4. 观察与反思（Observe / Reflect）：读取工具返回结果，判断任务是否完成、路径是否需要调整，然后回到第 2 步，直到达成目标或请求人类介入。

业界常把这个架构概括为公式：AI Agent = LLM（大脑）×（规划 + 记忆 + 工具 + 行动）。记忆分短期（当前任务的上下文窗口）与长期（外部数据库，常配合 RAG 检索）。

关键术语

LLM（大脑）：负责理解、推理与决策的推理引擎，是 Agent 的核心处理组件。
工具调用（Function Calling）：把模型的"想法"转化为实际函数调用，是 Agent 从"说"走向"做"的桥梁。
控制循环（Control Loop）：感知 → 推理 → 行动 → 观察 的循环编排器，决定何时行动、何时停止。
ReAct：推理（Reason）与行动（Act）交替进行的经典 Agent 模式（Yao 等，2022）。
MCP（Model Context Protocol）：标准化模型与外部工具连接的协议，相当于 Agent 的"工具插座"。

5应用场景

智能客服（企业服务）：客服 Agent 自动追问客户、检索内部文档、给出方案，并自行判断是当场解决还是转接人工——这是 AWS 文档给出的典型案例。
金融风控（金融业）：金融智能体实时监控交易流以检测欺诈活动与网络威胁，减少误报并提高交易安全性（据央广网报道的产业应用）。
科研模拟（学术界）：斯坦福"虚拟小镇"实验中，25-50 个智能体在数字社会中自主协作，模拟社区治理、资源分配等复杂任务。
开放性调研与排查（研发）：如"调研竞品上周动态并整理成对比表"这类路径不确定、需边做边判断的任务，正是 Agent 的主场。
不适用场景：步骤固定、规则清晰的任务。Anthropic 明确建议：路径可预先画在白板上的任务应使用 Workflow（固定流程编排），它更快、更便宜、更好调试。给这类任务硬上 Agent，只会得到更贵、更难排查的黑箱。

判断口诀：人提前写死路径的是 Workflow；模型当场决定路径的才是 Agent。RAG（检索增强生成）则介于 Chatbot 与 Workflow 之间——它让系统"更博学"，但检索链路仍是人写死的，并未更自主。

7自测问题

1.（判断）模型能力越强，就越应该用 Agent 而不是 Workflow 来完成任务。
参考答案错误。选型依据是任务路径是否确定，而非模型强弱——路径可预先编排的任务，用 Workflow 更快、更省、更易调试（Anthropic《Building Effective Agents》的建议）。
2.（选择）"人给目标，模型定路径"描述的是：A. Chatbot　B. Workflow　C. Agent
参考答案C。控制权在运行时由模型动态掌握是 Agent 的定义性特征。
3.（填空）业界常把 Agent 概括为公式：Agent = LLM ×（____ + ____ + ____ + ____）。
参考答案规划（Planning）+ 记忆（Memory）+ 工具（Tools）+ 行动（Action）。
4.（简答）你需要 AI 每天定时抓取三个固定数据源、按固定格式生成日报，该用 Agent 还是 Workflow？为什么？
参考答案Workflow。步骤与路径完全固定、可提前编排，用固定流程更快、更便宜、更好调试；Agent 的自主性在这里只会增加成本与不确定性。
5.（简答）Agent 的"短期记忆"存放在哪里？
参考答案存放在当前任务的上下文窗口中；跨任务的长期记忆需要外部存储（如数据库，常配合 RAG 检索）实现。
