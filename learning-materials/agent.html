2. 核心问题

  1. 同样是"用 LLM 完成任务"，Agent 比普通对话机器人多出来的关键能力是什么？
  2. Agent 为什么需要一个"循环"而不是一次调用就完事？这个循环的每一环在做什么？
  3. Anthropic 为什么建议"能不用 Agent 就不用"？它在什么情况下反而不如 Workflow？

3. 个人解释

把大语言模型想象成一位只坐在电话亭里的顾问：你问什么，他答什么，口才好、知识广，但他没有手——不能替你发邮件、不能帮你查数据库、不能真的去把事办了。而 Agent（智能体）就是给这位顾问配了一辆车、一个工具箱和一张任务清单：他不再只是"说"，而是接到一个目标后，自己规划先做什么后做什么，开车去现场（调用工具），看看结果如何（观察反馈），再决定下一步——直到把任务做完才回来向你汇报。

所以 Agent 的本质不是"更聪明的模型"，而是"模型 + 工具 + 记忆 + 一个自主循环"组成的系统：模型依然是那个大脑，但它被放进了一个可以反复"看一看、想一想、动一动"的工作回路里。Anthropic 在工程实践中给出的定义正是如此：Agent 是"LLM 动态指挥自己的处理过程和工具使用、自主掌控任务完成方式"的系统，与每一步都被代码预先写死的 Workflow 相对。

如果只能记住一句话：Agent 就是一个能用大模型当大脑、自己决定下一步做什么并调用工具把任务做完的系统。

4. 核心机制

起源

"智能体"是 AI 领域的老词，但在 LLM 时代的现代定义由产业实践推动成型：2022 年 ReAct 论文（Yao 等）提出"推理与行动交替"的范式；2024 年 12 月 Anthropic 发布《Building effective agents》，明确区分了 Workflow 与 Agent 两种"智能体系统"，成为业界引用最广的工程定义。

原理：一个循环 + 四大要素

Agent 的运行是一个不断重复的控制循环（control loop）：感知现状 → 用 LLM 推理下一步 → 调用工具行动 → 观察结果 → 再推理，直到任务完成或触达停止条件。支撑这个循环的四大要素：

  • LLM 大脑：负责拆解任务、决定下一步动作、生成最终答复。
  • 工具（Tools）：Agent 可以调用的函数/API——搜索、数据库、代码执行、发邮件等，是 Agent 的"手"。
  • 记忆（Memory）：短期记忆放在上下文窗口里（对话与工具结果），长期记忆靠向量库等外部存储。
  • 控制循环：决定何时思考、何时调用工具、何时停下来的调度逻辑；各框架（LangGraph、CrewAI 等）本质上是这个循环的不同实现。

关键要素（必掌握术语）

  • Augmented LLM（增强型 LLM）：配上检索、工具、记忆的 LLM，是 Agent 的基本积木。
  • Tool Calling（工具调用）：模型输出结构化指令调用外部函数的能力。
  • ReAct：推理（Reason）与行动（Act）交替进行的经典 Agent 范式。
  • Human-in-the-loop：高风险动作前暂停等待人工批准的机制。

5. 应用场景

客服 Agent（企业服务）：接入客户数据与知识库后，Agent 不只回答问题，还能实际执行查订单、办退款等操作；行业普遍按"成功解决量"计费，只在真正闭环时收费。
编程 Agent（软件开发）：以 Claude Code 为代表的编程 Agent 能自主完成编码任务，用自动化测试结果作为反馈不断迭代修正，直到测试通过，再由人工审查合并。
通用任务 Agent（个人生产力）：如 Manus 一类通用 Agent，在沙箱里自主完成网页调研、文件处理、代码执行等多步任务，把"数小时的电脑操作"压缩成"一句委托指令"。
不适用场景：流程固定、定义清晰的任务（如标准化的退款审批流）。此时每一步都能预先写死，用 Workflow 更便宜、更快、更可控——Agent 是用延迟和成本换灵活性，路径可预测时这笔交易不划算。

7. 自测问题

（判断）1. 只要系统里用到了 LLM，它就是 Agent。

参考答案

错。Anthropic 的区分标准是"谁决定下一步"：步骤由代码预先写死的是 Workflow；只有 LLM 动态指挥自身流程与工具使用时才是 Agent。

（选择）2. 下列哪一项不是 Agent 的四大组成要素？A. LLM 大脑 B. 工具 C. 记忆 D. 更大的训练数据集

参考答案

D。四要素是 LLM 大脑、工具、记忆、控制循环；训练数据集与 Agent 的架构无关。

（选择）3. 一个步骤完全固定、每天都能预测的任务，最适合用哪种形态实现？A. Agent B. Workflow C. 多 Agent 系统 D. ReAct

参考答案

B。路径可预测时 Workflow 更便宜、更快、更可控；Agent 的灵活性优势用不上。

（简答）4. 用一句话向没有技术背景的同事解释什么是 Agent。

参考答案

参考第 3 节：Agent 就是给只会动嘴的 AI 顾问配上工具和任务清单，让它自己规划、自己动手，把任务做完再向你汇报的系统。

（简答）5. Agent 的控制循环每一轮大致做哪三件事？

参考答案

感知/观察现状 → 用 LLM 推理决定下一步 → 调用工具行动并观察结果，如此往复直到任务完成或触达停止条件。
